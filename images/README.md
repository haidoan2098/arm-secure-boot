# images/

The four files to copy into the **boot partition (FAT32)** of the SD card when flashing
a BeagleBone Black.

| File | Source | Contents |
|---|---|---|
| `MLO` | U-Boot SPL — `board/ti/am335x/`, `arch/arm/cpu/armv7/`, `common/spl/` | Compiled code only, **no device tree** (`CONFIG_SPL_OF_CONTROL` disabled), **unsigned** (nothing can verify it on GP silicon) |
| `u-boot.img` | Two already-compiled pieces: `u-boot-nodtb.bin` (code) + 10 `.dtb` files from `arch/arm/dts/` (`am335x-evm`, `am335x-bone`, …, `am335x-boneblack`) | **Public key embedded** into the `am335x-boneblack` device tree only, via `tools/fdt_add_pubkey -a sha256,rsa2048 -k keys -n dev -r conf`, applied **before** the final packaging step — never run `make` afterwards, as it rebuilds the dtb from source and wipes the key |
| `fitImage` | `zImage` (Linux kernel build) + the kernel's device tree (`arch/arm/boot/dts/ti/omap/am335x-boneblack.dtb` in the **kernel** tree — a different file from U-Boot's same-named one above) | Hand-written FIT (`scripts/fit-image.its`): `images/kernel-1` + `images/fdt-1`, each with a SHA-256 hash, both covered by a single signature under `configurations/conf-1/signature-1` (prevents mix-and-match attacks) |
| `extlinux.conf` | No dedicated source — the original is generated by Yocto during image build | A few lines of config for U-Boot's generic distro boot (`boot/pxe_utils.c` reads it). The copy in this repo is modified: `kernel /zImage` + `fdtdir /` → `kernel /fitImage`, with `fdtdir` removed |

## `unsigned-reference/`

Unsigned originals of `zImage` and the two device trees — kept for before/after comparison
only, not used for flashing.
